# Test images (not included)

The six images used by `integration_test/benchmark_test.dart` are **not
distributed** with this repository: their copyright/consent status is unknown.

To run the benchmark, add your own images (ones you have the rights to) with
these exact names, or edit the file lists in `benchmark_test.dart`:

```
dermatho/12174-rosacea.jpg
dermatho/Atopic Dermatitis.jpg
dermatho/Molluscum-contagiosum_1.jpg
occulaire/Eyeliddisorders.jpg
occulaire/Uveitis.jpg
occulaire/images.jpg
```

`labels.json` holds the expected label for each file. Images in these folders
are git-ignored.
